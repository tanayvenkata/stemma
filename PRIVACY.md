# Privacy

Stemma collects, stores, and sends no data.

- It is a set of Markdown notes and instructions that your coding agent reads locally.
- It has no hooks, MCP servers, network access, or telemetry, and it reads no credentials.
- Its only executable, `skills/stemma/scripts/gate_stats.py`, runs locally: it reads only the counts or results file your agent passes to it, prints the statistics, writes nothing, and makes no network requests.

Whatever your agent does with your code or data is governed by that agent and its provider, not by Stemma.

Questions: open an issue at https://github.com/tanayvenkata/stemma/issues or email tanayvenkata@gmail.com.
